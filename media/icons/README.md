# Icon assets

- `bitfroest-app.png` is the extension package icon referenced by `package.json`. It is a 1254 × 1254 PNG.
- `bitfroest-vscode.svg` is a centered, single-color 24 × 24 SVG for an Activity Bar view container.

The current extension button is a Status Bar item. Status Bar item text supports VS Code product-icon identifiers such as `$(folder)` and `$(folder-opened)`. A custom SVG cannot be assigned directly to that item. A custom glyph there would require a product icon font and a product icon theme.
